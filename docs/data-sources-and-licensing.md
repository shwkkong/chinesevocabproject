# Data sources & licensing notes (Option A)

## Goal
Ship an offline dictionary/vocabulary catalog built from open (or properly licensed) datasets.

## CC-CEDICT
- CC-CEDICT is commonly used for Chinese-English lexical data.
- Ensure compliance with its license/attribution requirements.

## HSK lists
- HSK word lists exist in multiple forms; ensure license compatibility.
- We will map HSK level to dictionary entries by matching hanzi + pinyin where possible.

## Frequency
- Word frequency data can come from multiple corpora.
- Ensure the chosen dataset permits redistribution.

## Important note
This project does **not** ship Pleco’s proprietary dictionaries.
